
# BioMarket - Store Management System

## Project Overview

BioMarket is a Python-based command-line management system developed for a small store specializing in vegan and organic products.

The project focuses on inventory management, sales processing, profit calculations, and data persistence.

## Main Features

- Add new products to the inventory
- Update stock quantities
- Display available products and selling prices
- Record sales involving multiple products
- Automatically update inventory after sales
- Calculate total sales revenue and profit margins
- Save and load data using JSON
- Validate user inputs and handle errors

## Technologies Used

- Python
- JSON
- Jupyter Notebook / Google Colab
- Python Standard Library

## Available Commands

| Command | Description |
|---------|-------------|
| add | Add products to inventory |
| list | Display available products |
| sale | Register a sale |
| profits | Display revenue and profit |
| help | Show available commands |
| close | Exit the application |

## How to Run

1. Download the Python script.
2. Make sure Python 3 is installed.
3. Run the script from the terminal.
4. Follow the interactive command-line instructions.

Inventory and financial data are saved automatically in `biomarket_data.json`.
